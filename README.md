# Excel Sales Dashboard

## Overview

This project showcases an interactive Excel Sales Dashboard designed to analyze and visualize sales performance data. Using advanced Excel features such as Pivot Tables, Pivot Charts, Slicers, and Conditional Formatting, the dashboard provides valuable insights into sales trends, target achievement, regional performance, and employee productivity.

## Features

* Interactive dashboard with dynamic filtering using slicers
* Sales performance analysis across multiple regions
* Employee-wise sales tracking and comparison
* Target achievement and performance monitoring
* Data visualization using Pivot Charts
* User-friendly and professional dashboard design

## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Analysis

## Dataset
--<a href="https://github.com/SiddharthaSangani18/excel-sales-dashboard/blob/main/Sales_Dashboard_Data_150.xlsx">Dataset </a>

## Key Insights

* Identifies top-performing employees and regions
* Tracks sales performance against targets
* Highlights trends and patterns through visualizations
* Supports data-driven decision-making
